# Förslag: Overview och difftrådar

Tre alternativa riktningar med samma innehåll. Öppna kodblocken med ett
monospace-typsnitt för att jämföra avstånd och linjer.

| Förslag | Uttryck | Vad vi prövar |
| --- | --- | --- |
| [A · Mjukare original](a-mjukare-original.md) | Tydligt grupperade kommentarer | Behålla ramarna men minska konkurrerande detaljer |
| [B · Samtal med vänstermarkering](b-samtal.md) | Luftigare, färre linjer | Låta text och indrag skapa grupperna |
| [C · Kompakt trådlista](c-tradlista.md) | Överblick först | Visa hela samtalet först när man öppnar en tråd |

Det här är layoutskisser, inte skärmbilder från appen. A och B är främst
presentationsförändringar. C innebär också nytt beteende för att öppna och
stänga trådar i Overview. Kortkommandon i C är förslag.

Skisserna visar själva innehållsytan. Appens header och flikar är utelämnade
så att samma utrymme kan användas till jämförelsen. Footern visar relevanta
exempel på handlingar, inte hela uppsättningen.

Färger går inte att bedöma i dessa kodblock. För alla alternativ gäller:
standardbakgrund, normal textfärg för innehåll, dämpad metadata och en tydlig
fokusmarkering. Status skrivs ut så att färg inte behövs för att förstå den.

Jämför framför allt:

- Hittar du kommentarens innehåll direkt?
- Ser du vilken kommentar eller tråd som är markerad?
- Förstår du vad som är kod, svar respektive metadata?
- Är folden begriplig innan du har använt den?

Min utgångspunkt är A: du gillade originalets tydlighet. B och C hjälper oss
att se om mindre inramning faktiskt gör arbetet trevligare eller bara mindre tydligt.
